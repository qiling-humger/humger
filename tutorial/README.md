# 汉堡物语 · 初始岛 V2 · 五天新手关

当前主初始岛，使用 V2 素材和参考布局的 24×20 地图。入口：

```text
res://tutorial/TutorialLevel.tscn
```

本地双击：

```text
F:\humger\启动初始岛.bat
```

## 操作

- `WASD` / 方向键：移动
- `E`：采集、对话、做菜、交付、睡觉、取水/挖泥、启航
- `F`：小船建好后直接启航
- 餐厅内部：鼠标左键拖动厨房设备/桌椅，松开吸附网格
- 餐厅内部：`E` / `Esc` 返回岛屿
- `B`：建造餐厅/小船
- `1-3`：建造选择
- `鼠标左键`：放置
- `Esc`：关闭商店/取消
- `F5` / `F9`：保存/读取
- `H`：提示

## 已实现
