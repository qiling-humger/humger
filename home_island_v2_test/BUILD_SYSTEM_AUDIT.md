# 自由摆放系统能力检查（本轮更新）

本轮只修贴地锚点和旋转，没有重写建造系统。

## 已实现

- 统一逻辑网格坐标 `Vector2i`
- 隐藏式网格；建造时显示网格
- 物件 ID、宽度、高度、阻挡属性
- `allow_rotation`、`anchor` 物件字段
- 1×1、2×1 以及任意 `width × height` 占格
- 单元格吸附，不会出现半格偏移
- 建造模式、物件选择、鼠标放置
- 拖动搬动、Esc 取消、失败回滚
- 右键拆除
- 绿色合法预览 / 红色非法预览
- 完整占地范围预览
- 重叠、水面、边界、玩家脚下的放置校验
- 多格 footprint 的占位与释放
- 纹理 alpha 最低点作为底部锚点
- 1×1 / 多格物件统一以占地中心为底部中心
- 接触阴影使用同一底部锚点
- `R` 顺时针 90°、`Shift+R` 逆时针 90°
- 放置预览和拖拽状态下都可旋转
- 旋转后占格宽高、碰撞、绿红校验同步
- 旋转后保留朝向并写入存档
- 桌子提供 0/90/180/270 的朝向状态；90/270 使用 1×2 变体贴图

## 尚未实现

- 任意家具都具备四向独立美术贴图；目前只有桌子提供 1×2 变体
- 桌椅成套推荐位置
- 物件边缘对齐提示
- 相邻物件间距提示
- 可选对齐辅助线
- 2×2、3×2 等大型物件样例与专门测试
- 建筑类物件的完整旋转规范
- 任意旋转角度（当前严格 90°）

## 结论

贴地锚点和 90° 旋转已经接入现有网格/预览/搬动/存档系统；  
布局辅助和更多尺寸的样例属于下一阶段，不与本轮混做。
