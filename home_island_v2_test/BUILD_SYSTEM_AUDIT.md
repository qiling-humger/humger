# 自由摆放系统能力检查

本报告只审计现状，本轮没有重写或新增大型建造功能。

## 已实现

- 统一逻辑网格坐标 `Vector2i`
- 隐藏式网格；建造时显示网格
- 物件 ID、宽度、高度、阻挡属性
- 1×1、2×1 以及任意 `width × height` 占格（当前测试只覆盖 2×1）
- 单元格吸附：物件原点取最近整数格，不会出现半格偏移
- 建造模式、物件选择、鼠标放置
- 拖动搬动、Esc 取消、失败回滚
- 右键拆除
- 绿色合法预览 / 红色非法预览
- 完整占地范围预览
- 重叠、水面、边界、玩家脚下的放置校验
- 多格 footprint 的占位与释放
- 物件位置存档与启动恢复

## 尚未实现

- 90° 旋转和旋转后的 footprint 重算
- 物件的 `rotation`、`allow_rotation`、`anchor` 等字段
- 旋转后的碰撞、遮挡和预览同步
- 物件边缘对齐提示
- 相邻物件间距提示
- 桌椅成套推荐位置
- 可选对齐辅助线 / 布局参考提示
- 2×2、3×2 等大型物件的样例与专门测试
- 建筑类物件的独立旋转/锚点规范
- 物件视觉尺寸与占地尺寸的通用自动校准；目前依赖每个素材的 `display_scale` 和 `base_pad`

## 结论

当前系统已经支持**自由放置、搬动、取消、拆除、网格吸附和占用校验**，可以支撑第一轮 V2 美术测试。  
旋转与布局辅助是下一阶段需要新增的能力，本轮没有擅自实现。
