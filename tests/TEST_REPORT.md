## 3. 覆盖项

### 启动与场景
- `Main.tscn` 实例化成功。
- 启动进入标题状态，HUD 隐藏。
- 8 个功能设备注册成功。
- 标题状态禁止移动。
- 鼠标点击“开始营业”进入营业。
- 所有设备交互点通过网格 BFS 可达性检查。
- 所有设备交互点可直接站立，不被其他设备碰撞框覆盖。
- 顾客按到店计时自动生成。

### 玩家与交互
- WASD 屏幕方向移动有效。
- 键盘 E 事件可触发设备交互。
- 键盘 ESC 暂停 / 恢复。
- 鼠标点击暂停菜单“继续营业”恢复。
- 鼠标直接点击生肠冷柜可取出生肠，修复最左侧生肠被酱料台挡住的问题。
- 交互范围最近设备高亮与提示。

### 完整订单闭环
- 生肠冷柜取生热狗肠。
- 煎烤台放入，占用烤位。
- 火候 9 秒为“完美”。
- 取出后品质为完美。
- 烤肠放上组装台。
- 面包篮取面包。
- 面包合上热狗。
- 拿起成品热狗。
- 番茄酱台加酱。
- 交付正确订单获得金币、接待数 +1。
- 先放面包、后放烤肠的另类流程也能完成组装。

### 经济与惩罚
- 错误酱料交付：扣金币、扣满意度、错误统计 +1、顾客离店。
- 顾客耐心耗尽：计入流失、扣满意度。
- 生肠/未熟热狗不能通过订单校验。
- 连续完成 3 笔订单，金币持续增加，队列正确清空。

### 流程
- 手动暂停 / 继续。
- 营业时间耗尽自动结算，原因 `shift_end`。
- 满意度归零提前打烊，原因 `satisfaction`。
- 结算界面显示评级、金币、接待、完美数、失误/流失、满意度、平均品质。
- 鼠标点击结算“再开一局”后恢复营业状态。
- 重开后金币归零、空手、HUD 恢复。

### 纯数据边界
- 0 秒 = 生的。
- 4 秒 = 加热中。
- 6.5 秒 = 刚刚熟透。
- 20 秒 = 烤焦。
- 生肠不能交付。

## 4. 已知环境提示

启动 Godot 时会打印：

```text
ERROR: Failed to read the root certificate store.
```

这是当前 Windows 用户环境读取系统证书存储的权限/可用性问题，发生在引擎启动阶段，不影响本项目的离线运行、渲染和输入。游戏进程仍正常退出 0。

无头模式的另一个限制：

```text
[SKIP] 鼠标点击...（无头模式没有 GUI 输入）
```

不是游戏缺陷；窗口模式已验证鼠标点击全部通过。
